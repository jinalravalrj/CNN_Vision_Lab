What is a CNN?

A Convolutional Neural Network (CNN) is a deep learning architecture designed to process grid-like data such as images. It automatically learns spatial hierarchies of features — from low-level edges to high-level object parts — through a series of learnable filters.

This lab uses MobileNetV2, a pretrained CNN with ImageNet weights, to classify real images into 1,000 categories with fast, accurate inference.

MobileNetV2 — Actual Architecture

MobileNetV2 does not use standard conv → pool blocks. Its key innovations are:

1. Depthwise Separable Convolution
Splits standard conv into a depthwise conv (per-channel spatial filter) + a pointwise 1×1 conv. Reduces computation by ~8–9×.
2. Inverted Residual Blocks
Expands channels in bottleneck (expansion ratio 6), applies depthwise conv, then projects back to fewer channels. Skip connection added when input == output shape.
3. Global Average Pooling
Replaces Flatten + large Dense layers. Averages each feature map to a single number, dramatically reducing parameters.
4. Final Dense (1000)
Softmax over 1,000 ImageNet classes. Total parameters ≈ 3.5 M — very efficient for mobile deployment.

Understanding Train / Val / Test Splits

Train
Training Data
Used to update the model weights via backpropagation. Typically 70–80% of the dataset.
Val
Validation Data
Used to tune hyperparameters and check for overfitting during training. Typically 10–15%.
Test
Test Data
Held-out set used only once after training is complete to give an unbiased estimate of real-world performance. Typically 10–15%.

About This Project

BCA Neural Network Subject Project — CNN Vision Lab

🎯 Project Objective

To design, implement, and demonstrate a complete web-based application that showcases how a Convolutional Neural Network works in practice — from raw pixel input to classification output — using real model inference, interactive visualizations, and educational content.

❓ Problem Statement

Traditional neural network courses lack interactive tools that let students observe the actual internal workings of a CNN. This project bridges that gap by providing a hands-on platform where every stage of inference — convolution, activation, pooling, classification — can be explored with real model outputs.

🏗️ CNN Architecture

1. Input – Raw pixel data (224×224×3 for MobileNetV2)
→
2. Conv + ReLU – Learnable filters detect spatial patterns
→
3. Pooling – Reduces spatial dimensions, retains important features
→
4. Repeat – Deeper layers learn abstract features
→
5. GAP / Flatten – Converts feature maps to a vector
→
6. Dense + Softmax – Produces class probabilities

⚙️ Workflow

  1. User uploads an image via the browser.
  2. JavaScript validates type and size client-side.
  3. Flask validates the upload server-side.
  4. Pillow reads and resizes the image to 224×224.
  5. MobileNetV2 preprocessing normalises pixel values.
  6. Model runs forward propagation and returns 1,000-class probabilities.
  7. Top-3 predictions decoded from ImageNet class labels.
  8. Result stored in SQLite and returned to the browser.

🌍 Applications of CNNs

  • Medical imaging — tumour detection, X-ray analysis
  • Autonomous vehicles — object and pedestrian detection
  • Facial recognition and biometrics
  • Document OCR and handwriting recognition
  • Agricultural disease detection in crops
  • Quality control in manufacturing
  • Content moderation on social platforms

⚠️ Limitations

  • MobileNetV2 is pretrained on ImageNet; it cannot recognise arbitrary objects outside those 1,000 classes.
  • Predictions can be wrong — no model achieves 100% accuracy.
  • Custom training requires a GPU or significant time on CPU.
  • The feature-map visualisation shows only the first conv layer.
  • The app does not retain uploaded images after prediction.

🚀 Future Enhancements

  • Support for additional models (ResNet50, EfficientNet, VGG16).
  • Grad-CAM visualisation to highlight which image regions influenced predictions.
  • Drag-and-drop multi-image batch classification.
  • Training progress visualised in real-time via WebSocket.
  • Export predictions and metrics as a PDF report.
